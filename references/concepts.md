# 选房方法论与房产概念库

本文件只沉淀**方法论与概念**，不含任何具体城市数据。具体数据一律按 `data_sources.md` 实时搜索。
用于：向用户解释概念、指导评分、主动教育。

## 一、看懂小区的核心指标

| 指标 | 含义 | 怎么算好 |
|------|------|---------|
| 容积率 | 地上总建筑面积 ÷ 用地面积 | ≤2.0 舒适低密；2.0-3.0 常规高层；>3.5 拥挤。容积率每高一点，楼间距、采光、电梯等待都打折 |
| 绿化率 | 绿化用地占比 | ≥35% 优秀，30% 及格线 |
| 公摊 | 建面 - 套内 | 高层公摊 20-27% 常见；得房率低于 72% 要警惕 |
| 梯户比 | 几部电梯服务几户 | 一梯两户/两梯两户舒适；两梯四户常规；三梯八户以上是宿舍感 |
| 楼层净高 | 地板到天花板 | ≥2.8m 舒适；<2.7m 压抑 |
| 楼间距 | 前后楼距离 | 粗略：不低于前楼高度的 1.2 倍，否则低楼层冬天采光差 |

## 二、户型与楼栋选择

- **边套 vs 中间套**：边套三面采光通风好但价格贵；西边套有西晒问题但通常最便宜；中间套注意南北通透与否、有无暗间
- **楼层**：高层住宅避开扬灰层说法（无科学依据，不必当真）；真正要避的是腰线层（渗水风险）、设备层（噪音）、顶层（漏水与夏热风险，除非送阁楼/露台）、底层（潮湿、采光、隐私，除非送花园）
- **朝向**：南向 > 东南 > 东 > 西南 > 西 > 北；主卧和客厅朝南是基础要求
- **板楼 vs 塔楼**：板楼通风采光好、公摊小；塔楼公摊大、部分户型有暗间

## 三、需求分析方法论

### 三层需求模型

| 层级 | 定义 | 处理方式 |
|------|------|---------|
| 硬性条件 | 不满足就淘汰 | 作为搜索过滤条件 |
| 强烈偏好 | 很在意但可商量 | 作为评分加权 |
| 锦上添花 | 有更好 | 同分时决胜 |

### 经典矛盾对（主动帮用户识别）

| 矛盾 | 甜蜜点 |
|------|------|
| 近地铁 vs 安静 | 距地铁 800m-1.2km，不临街 |
| 低总价 vs 大空间 | 牺牲地段换面积，或牺牲面积换地段，帮用户想清楚哪个更不能妥协 |
| 学区 vs 居住品质 | 老破小学区 vs 次新无学区；提醒学区政策变动风险 |
| 新房 vs 二手房 | 新房品质新但有交付风险+等 2-3 年；二手所见即所得但楼龄老 |
| 楼层低（方便老人） vs 采光好 | 楼间距大的小区低楼层也可接受 |

### 深挖参考标的（用户提到喜欢的小区时必做）

追问三连：
1. "最吸引你的是哪一点？"
2. "有没有觉得不够好的地方？"
3. "如果能改一个地方，你最想改什么？"

从回答中提炼用户对"好房子"的真实定义，并以该小区为基准线做后续对比。

## 四、购房财务知识（主动教育用）

- **满五唯一**：房产证满 5 年且是卖方家庭唯一住房，免增值税+个税——二手房大额成本差异点
- **契税**：通常 1-3%（首套/面积段阶梯），以当地最新政策为准
- **定金 vs 订金/诚意金/认筹金**：定金有担保性质，买方违约不退；后三者法律上可退，但签协议时仍要看清条款
- **月供红线**：月供不超过家庭月收入 50%（银行审批线），舒适线是 35%
- **公积金**：利率低于商贷，额度有上限，各地政策差异大——必须实时查当地政策
- **隐藏成本**：装修（毛坯约 1500-3000 元/㎡）、物业费、车位（买或租）、维修基金、中介费（二手房通常 1-3%）

## 五、交易流程要点

### 新房（期房）
认购（交定金/认筹金）→ 签预售合同 → 办贷款 → 等待交付（1-3 年，**交付风险敞口期**）→ 交付验房 → 办证

关键风险点：
- 付定金前确认五证齐全
- 预售资金是否进监管账户
- 交付标准写进合同附件，精装房尤其注意品牌型号
- 延期交付违约金条款

### 二手房
看房 → 产调（查抵押查封）→ 签合同付定金 → 资金监管 → 过户 → 交房（户口/物业结清）

关键风险点：
- 产调必做，确认无查封无未披露抵押
- 户口迁出写进合同并约定违约金
- 学区占用情况核实（打学校或教育局电话）
- 买卖不破租赁，确认无租约

## 六、板块分析框架

分析一个板块时按此框架搜信息（结论写入 research.md）：

1. **能级定位**：城市主中心/副中心/睡城/远郊？看官方国土空间规划
2. **交通现状与规划**：已通地铁 vs 在建 vs 规划中（只认发改委批复）
3. **产业与人口**：有什么产业、导入什么人群——决定接盘侠质量
4. **供应与库存**：库存高压板块涨价乏力
5. **学区与配套**：教育/医疗/商业的质与量
6. **价格位置**：当前均价在本城市的价格带位置，近三年走势

## 七、常见坑速查（主动提醒时机）

| 坑 | 提醒话术场景 |
|----|-------------|
| 高出租率/群租小区 | 用户看低总价次新小区时 |
| 临街噪音 | 推荐房源临主干道/高架时 |
| 顶楼漏水 | 推荐顶楼房源时 |
| 公寓/商住 | 用户预算紧张可能被推荐公寓时：40 年产权、商水商电、不能落户、无学区、税费高、转手难 |
| 远郊大盘 | 通勤时间实测比地图测算更残酷，高峰期+换乘 |
| 法拍房 | 价格诱人但腾房、欠费、租约风险高，非专业人士慎入 |
| 串串房 | 装修精美但低价买入翻新的投机房，材料差、甲醛超标 |
