# 避坑排查清单（风险排查 SOP）

对每一个入围候选（小区/楼盘）逐一执行本清单。**宁可漏掉一个好房子，不可漏掉一个雷。**

排查结果统一记录到 `.dream-house/research.md`，格式：`[结论] 事实描述 [来源, 日期]`。

## 一、开发商风险排查

### 1.1 经营与财务健康度

| 查什么 | 怎么查 | 红旗信号 |
|--------|--------|---------|
| 工商状态、股权出质、法律诉讼 | 天眼查/企查查/爱企查（WebFetch 搜索摘要即可） | 经营异常、大量股权出质、被执行人记录 |
| 债券违约、商票逾期 | 搜索 `"{开发商名}" 债券 违约` / `"商票 逾期"` | 任何未兑付记录 |
| 欠薪/停工舆情 | `"{开发商名}" 欠薪 停工 2026` | 近 180 天内有集中舆情 |
| 三道红线/债务规模 | 财经新闻（财新/第一财经/界面等） | 净负债率畸高、现金短债比 <1 |

### 1.2 历史交付记录

| 查什么 | 怎么查 |
|--------|--------|
| 其他项目是否延期交付 | `"{开发商名}" 延期 交付` / `"{开发商名}" 烂尾` |
| 交付质量口碑 | `"{开发商名}" 交付 减配 维权`、小红书/知乎搜开发商名+交付 |
| 同城市已交付项目表现 | `"{城市} {开发商名}" 交付 业主` |

**判定参考**：近 3 年内有项目延期交付 → 风险维度扣 4-8 分；有停工/烂尾未解决 → 若目标项目未交付则一票否决。

## 二、项目层面排查（新房/预售房重点）

| 查什么 | 怎么查 | 红旗信号 |
|--------|--------|---------|
| 五证（国有土地使用证、用地规划许可证、工程规划许可证、施工许可证、预售许可证） | 当地住建局/房管局官网预售证公示；搜索 `"{楼盘名}" 预售证` | 查不到预售证却已在收钱 → 一票否决 |
| 预售资金监管 | 搜索 `"{楼盘名}" 资金监管`、`"{城市}" 预售资金监管 政策` | 监管账户异常舆情 |
| 土地抵押/在建工程抵押 | 地方不动产登记中心公示（部分城市可查）、天眼查项目公司 | 大额抵押且开发商资金紧张 |
| 施工进度 | 搜索 `"{楼盘名}" 施工 进度 2026`、小红书/抖音工地实拍 | 与宣传节点严重不符 |

## 三、物业风险排查

| 查什么 | 怎么查 | 红旗信号 |
|--------|--------|---------|
| 物业公司背景 | 小区名+物业，查物业品牌（万科物业/绿城服务/龙湖智创生活等品牌物业通常更稳） | 开发商自有小物业且口碑差 |
| 投诉量与类型 | 黑猫投诉搜物业名；人民网领导留言板搜小区名 | 投诉集中在停水停电/电梯故障/安保缺失 |
| 物业费与服务匹配 | 业主口碑（小红书/知乎/业主群讨论） | 物业费高但服务差、物业费长期收不上来（恶性循环前兆） |
| 业委会纠纷 | `"{小区名}" 业委会 物业 纠纷` | 长期换不掉物业、激烈冲突 |

## 四、小区层面排查

### 4.1 通用

| 查什么 | 怎么查 |
|--------|--------|
| 维权历史 | `"{小区名}" 维权` / `"{小区名}" 业主 投诉` |
| 质量投诉 | `"{小区名}" 漏水 开裂 减配 虚假宣传` |
| 周边不利因素 | 卫星地图/街景查看：高架、铁路、垃圾站、变电站、殡仪馆、化工厂、加油站；搜索 `"{小区名}" 高架 噪音` |
| 出租率/群租 | `"{小区名}" 出租 群租`、问中介 | 
| 凶宅（二手房） | `"{小区名}" 凶宅`；签约前要求中介书面承诺 |

### 4.2 二手房专项

| 查什么 | 怎么查 | 红旗信号 |
|--------|--------|---------|
| 产权清晰 | 签约前要求查不动产登记（产调） | 共有产权人未同意、继承未完成 |
| 查封/抵押 | 产调可见；执行信息公开网查房 | 有查封 → 一票否决 |
| 户口占用 | 合同约定迁出时限与违约金 | 学区被占用、户口拒不迁出 |
| 租约 | 买卖不破租赁 | 长租约未到期 |
| 满五唯一/税费 | 房产证日期、业主家庭住房套数 | 税费口径不清导致成本激增 |

## 五、官方查询渠道速查

| 渠道 | 用途 |
|------|------|
| 天眼查 / 企查查 / 爱企查 | 开发商与项目公司工商信息、诉讼、股权出质 |
| 中国裁判文书网 | 开发商/物业/小区相关判决 |
| 中国执行信息公开网 | 被执行人、失信记录 |
| 信用中国 | 行政处罚、失信惩戒 |
| 地方住建局/房管局官网 | 预售证公示、资金监管政策、项目备案 |
| 黑猫投诉 | 物业与开发商投诉量 |
| 人民网领导留言板 | 业主向政府反映的问题（烂尾、办证难高发地） |
| 地方不动产登记中心 | 产调（抵押/查封），通常需业主配合 |

## 六、口碑渠道速查

| 渠道 | 特点 |
|------|------|
| 小红书 | 看房日记、交付实拍、业主吐槽（用 `scripts/search_xiaohongshu.py`） |
| 微信公众号 | 本地楼市测评、交付跟踪（用 `scripts/search_wechat.py`） |
| 知乎 | 深度讨论、"住在 XX 小区是什么体验" |
| 微博/抖音 | 维权事件首发地 |
| 本地论坛 | 如杭州口水楼市/19 楼、上海篱笆网等，真实但需甄别情绪 |
| 贝壳/链家小区页 | 带看评价、成交记录（成交价真实度较高） |

## 七、排查结论格式

每个候选排查完，输出：

```
## {小区名} 风险排查 [核查时间: YYYY-MM-DD]
- 开发商: {名称} —— {结论，一句话} [来源, 日期]
- 项目证件: {结论}
- 物业: {名称} —— {结论}
- 纠纷/维权: {结论}
- 不利因素: {结论}
- 风险灯: 🟢 无重大风险 / 🟡 有瑕疵需知悉 / 🔴 高风险慎入 / ⛔ 一票否决
- 未核实项: {列出让用户线下核实的事项}
```
