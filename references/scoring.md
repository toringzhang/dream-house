# dream-house 评分体系细则（0-100 分）

总分 = 7 维度得分之和。每个维度必须写出打分理由和依据（来源+日期）。
打分不是精密科学，但必须**可解释、可横向对比**——同一批候选用同一把尺。

## 一票否决项（先排雷，再打分）

命中以下任一项 → **直接淘汰，不打分**，报告中只写"淘汰原因"并附证据：

| 否决项 | 判定依据 |
|--------|---------|
| 停工/烂尾且未解决 | 近期（180 天内）舆情、业主投诉、官方通报 |
| 产权纠纷、查封 | 裁判文书网、执行信息公开网、中介核实 |
| 开发商债券违约且该项目未交付 | 债券公告、财经新闻、天眼查/企查查 |
| 五证不全（预售房） | 地方住建局/房管局预售证公示查询不到 |

## 七维度打分锚点

### 1. 地段与通勤（15 分）

| 分数档 | 锚点 |
|--------|------|
| 13-15 | 距地铁 ≤800m，通勤到用户工作地点 ≤40 分钟，板块为城市主/副中心 |
| 10-12 | 距地铁 ≤1.2km，通勤 ≤60 分钟，板块配套成熟 |
| 7-9 | 距地铁 ≤2km 或依赖公交接驳，通勤 ≤75 分钟 |
| 4-6 | 远郊，通勤 >75 分钟，板块能级弱 |
| 0-3 | 与用户通勤/生活圈严重不匹配 |

**必须基于用户实际通勤地点打分**；用户未提供通勤地点时按板块能级给中性分并注明假设。

### 2. 价格与性价比（15 分）

| 分数档 | 锚点 |
|--------|------|
| 13-15 | 挂牌/成交价低于同板块同品质均价 5% 以上，或近 90 天成交价企稳/微降有议价空间 |
| 10-12 | 与板块均价持平，定价合理 |
| 7-9 | 高于板块均价 5-10%，需有明确支撑（学区/品质/楼龄） |
| 4-6 | 高于板块均价 10% 以上且支撑不足 |
| 0-3 | 明显溢价或价格异常（需警惕串串房/虚假房源） |

价格数据必须 ≤30 天。对比基准优先用**近 90 天真实成交价**而非挂牌价。

### 3. 小区品质（20 分）

由四个子项构成，各 5 分：

| 子项 | 好（4-5） | 中（2-3） | 差（0-1） |
|------|----------|----------|----------|
| 楼龄与维护 | ≤10 年或维护口碑好 | 10-20 年 | >20 年且维护差（老破小除非学区极强） |
| 容积率/密度 | ≤2.0 低密 | 2.0-3.0 | >3.5 高密拥挤 |
| 户型与梯户比 | 南北通透、边套、两梯两户/一梯两户 | 中间套、两梯四户 | 暗间、纯北向、三梯八户以上 |
| 绿化与园区 | 绿化率 ≥35%、人车分流 | 30-35% | <30%、人车混行 |

二手房结合实地看房照片/VR 评价；新房结合样板间与交付标准口碑。

### 4. 生活配套（15 分）

| 分数档 | 锚点 |
|--------|------|
| 13-15 | 对口优质学区（用户有需求时）、步行圈内有商业综合体、三甲医院 ≤5km、公园绿地可达 |
| 10-12 | 配套齐全但非顶级；或用户无学区需求时商业/医疗/公园齐全 |
| 7-9 | 基础配套有（菜场/社区商业/社区医院），大型配套需车程 |
| 4-6 | 配套明显短板，依赖驾车 |
| 0-3 | 配套荒漠 |

**学区信息必须以最近一年官方划分为准**，并提示"学区政策可能调整"风险。用户无学龄儿童时，学区子项权重转移到商业/医疗，并注明。

### 5. 板块前景（5 分）

| 分数档 | 锚点 |
|--------|------|
| 5 | 有已批复的官方规划利好（地铁在建/重大产业落地），来源为政府公告 |
| 3-4 | 有规划但落地时间不确定 |
| 1-2 | 仅概念炒作，无官方文件支撑 |
| 0 | 板块利空（如规划利空、产业迁出） |

只认**官方规划文件/政府公告**，自媒体"规划利好"不作为加分依据。

### 6. 开发商与物业口碑（15 分）

开发商 8 分 + 物业 7 分：

| 对象 | 好 | 中 | 差 |
|------|-----|-----|-----|
| 开发商（8） | 央国企/头部稳健房企，历史项目按时交付、无重大维权（7-8 分） | 中型房企，偶有投诉但无恶性事件（4-6） | 有违约/延期/减配/大规模维权记录（0-3） |
| 物业（7） | 品牌物业，业主评价好，物业费与服务匹配（6-7） | 普通物业，偶有投诉（3-5） | 投诉高发、业委会与物业长期冲突、物业费收缴率纠纷（0-2） |

依据：天眼查/企查查经营状态、黑猫投诉量、人民网领导留言板、知乎/小红书/业主论坛口碑（需 ≥2 个独立来源）。

### 7. 纠纷与交付风险（15 分）

这是扣分制维度：从 15 分起扣。

| 风险项 | 扣分 |
|--------|------|
| 小区有维权历史但已解决 | -2 ~ -4 |
| 质量投诉（漏水/开裂/减配）有实锤 | -3 ~ -6 |
| 物业诉讼/业委会纠纷进行中 | -2 ~ -4 |
| 周边不利因素（高架/垃圾站/变电站等）未在前期披露 | -2 ~ -5 |
| 预售房：开发商资金链紧张舆情 | -5 ~ -8 |
| 预售房：同开发商其他项目延期交付 | -4 ~ -8 |
| 预售房：项目施工进度异常（停工传闻） | -8 ~ -15 |
| 二手房：户口占用/租约未清/学区被占用 | -3 ~ -6 |

扣到 ≤0 分视为高风险，报告中必须显著提示。

## 置信度标注

每个候选的总分旁必须标注置信度：

| 置信度 | 判定 |
|--------|------|
| **高** | 关键维度（价格、口碑、风险）均有 ≥2 个独立来源交叉验证，且数据在时效红线内 |
| **中** | 主要维度有 1 个可靠来源，或部分数据临近时效红线 |
| **低** | 存在无法验证的关键信息（如查不到成交价、口碑只有单一来源） |

置信度为"低"的候选，推荐时必须明示"哪些信息无法核实"，并给出用户自行核实的路径。

## 评分输出格式

每个候选的评分必须附带**打分理由**，格式：

```
地段与通勤 12/15 —— 距 5 号线 XX 站约 900m（高德地图，2026-10），
驾车至阿里西溪园区约 25 分钟；板块为城西科创大走廊核心区。
```

没有理由的分数无效。没有来源的事实无效。
